# Island Recipes

A full-stack mobile app to organize and search our personal recipes.

## Tech Stack

* **React Native / Expo** — JavaScript frontend
* **Spring Boot / Gradle** — Java backend
* **MongoDB Atlas** — Database
* **Edamam API** — Nutritional information
* **Cloudinary** — Image storage
* **OCR Space API** — Recipe parsing from photos
* **Axios** — HTTP client

## Features

* **Save & edit recipes** — Add, update, and delete recipes with photos, ingredients, instructions, and tags
* **Browse & search** — List all recipes or search by name and ingredient
* **Recipe tags** — Categorize recipes by protein, meal type, diet, and style; add custom tags too
* **Recipe photo import** — Photograph a printed recipe and let OCR parse it directly into the form
* **Meal randomizer** — Generate a random weekly menu, filter by protein type, and lock individual meals to keep them across re-rolls
* **Nutritional info per serving** — Calories, fat, protein, cholesterol, and sodium calculated per serving based on the ingredient list
* **PDF preview & sharing** — Preview a styled recipe card using the native print panel, then save or share as a PDF
* **Cooking mode** — Distraction-free view with free-hand draw to cross off ingredients and steps
* **Shopping list** — Tap any ingredient on a recipe to add it to the cart
